# 🐧 Guía de comandos Linux

Colección de comandos utilizados en administración de servidores Linux.

## 🔧 Procesos
ps aux

## 🌐 Puertos
ss -tulpn

## ⚙️ Servicios
systemctl status
systemctl restart

## 🎯 Uso
Estos comandos fueron utilizados en la configuración de un servidor Ubuntu para despliegue de aplicaciones.
